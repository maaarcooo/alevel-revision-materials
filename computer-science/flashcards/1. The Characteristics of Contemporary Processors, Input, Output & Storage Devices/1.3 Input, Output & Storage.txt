What is an input device? | A hardware component used to put data and commands into a computer system
A hardware component used to put data and commands into a computer system — what term is this? | Input device
What is an output device? | A hardware component that receives information from a computer and presents it to the user
A hardware component that receives information from a computer and presents it to the user — what term is this? | Output device
Give an example of a device that is both an input and an output device | A touchscreen, which displays output like a monitor and accepts touch input
What is a barcode reader used for? | Reading information from printed labels and cards, as in supermarket checkouts, stock control and access control
What is a magnetic stripe reader used for? | Reading the data on the magnetic stripe of a card such as a credit or debit card
What is a graphics tablet used for? | Drawing or sketching directly into a computer, for graphic design and other visual creative work
What are biometric devices used for? | Verifying a user's identity for security, for example by fingerprint or facial recognition
What is a scanner used for? | Digitising physical documents or images into a form the computer can process
What is a plotter used for? | Printing large, high-quality diagrams and designs, as in engineering and architecture
What is a braille display used for? | Outputting text in Braille so that visually impaired users can read it
How is computer-controlled machinery an output device? | The computer outputs commands directly to the machinery to control it, as in manufacturing and robotics
Which two performance factors matter when choosing an input device? | The speed and the accuracy of input
Besides cost, which three factors should be considered when recommending a device for a situation? | The user's needs, the user's skills and the environment in which it will be used
Give an example of the environment affecting the choice of device | A wired mouse suits a public computer lab because it is harder to steal, while a wireless mouse suits an uncluttered office
What is secondary storage? | Non-volatile storage that keeps files, applications and other data when the computer is powered off
Name the three types of secondary storage | Magnetic, optical and flash
Which four factors should be considered when recommending a storage device? | Capacity needed, speed of access needed, portability and cost
How does magnetic storage represent binary data? | Regions of magnetic material are either polarised or unpolarised, and a read/write head detects which state each region is in
How does a hard disk drive work? | Magnetic platters spin at high speed under a read/write head on an actuating arm, which can reach any part of a platter
Why do most hard disk drives contain several platters? | Stacking platters maximises the storage capacity
Give two benefits of magnetic storage | High capacity and a low cost per gigabyte
Give two drawbacks of a hard disk drive | Data transfer is relatively slow, and its moving parts and brittle platters are easily damaged by movement
What is magnetic storage best suited to? | Storing large amounts of data cheaply, such as backups and long-term storage
How did magnetic tape store data? | Tape wound on reels was passed through a reader that checked the polarity of each part to read off binary values
How is data read from an optical disc? | A laser is shone on the spiral track. Flat areas called lands reflect the light and recessed areas called pits scatter it
On an optical disc, which binary values do pits and lands represent? | Pits represent 0 and lands represent 1
How do CD-R, CD-RW and CD-ROM differ? | CD-R can be written once, CD-RW can be rewritten, and CD-ROM is written during production and can only be read
How do the capacities of CD, DVD and Blu-ray compare? | A CD holds about 700 MB, a DVD 4.7 to 9 GB, and a Blu-ray disc 25 to 50 GB
What is each of CD, DVD and Blu-ray typically used to store? | CDs store audio, DVDs store video, and Blu-ray discs store high-resolution films
Give two benefits of optical storage | Discs are cheap to mass-produce, and they are thin and light so easy to transport
Give two drawbacks of optical storage | Low capacity and slow transfer speeds compared with hard disks and SSDs, and discs are easily scratched
How does flash storage represent binary data? | Semiconductor logic gates (NAND and NOR) hold electrical charge in one of two states, high or low
How is the data in flash memory organised? | In pages, which are grouped into blocks
Which type of flash memory is preferred for small amounts of data such as code, and which for large files? | NOR for small amounts of data such as code. NAND for large files such as photos and videos
Flash memory can be erased and reprogrammed [...] | electronically
How does flash memory differ from RAM? | Flash memory is non-volatile, so it keeps its data without power. RAM is volatile
Give three advantages of an SSD over a hard disk drive | Faster data transfer, no moving parts so it resists damage from movement, and it is lighter
What limits the lifespan of an SSD? | Each write to a page raises the voltage needed to write to it again, until the page can no longer be written to
What is the main disadvantage of flash storage compared with magnetic and optical storage? | It costs more per gigabyte
Which type of storage best suits a task needing fast access to data, such as video editing? | Flash storage (an SSD)
Which storage devices suit moving data between computers? | USB flash drives and external hard disk drives or SSDs
What type of storage are RAM and ROM? | Primary storage (main memory)
What does volatile mean? | The memory loses its contents when the power is lost
What is RAM? | Fast, volatile main memory that holds the data and programs the computer is currently using
Fast, volatile main memory that holds the data and programs the computer is currently using — what term is this? | RAM (random access memory)
Why is RAM described as random access? | The processor can access any part of it equally quickly
Why does adding more RAM improve performance? | More data and programs can be held in fast memory at once
Why does a computer have far less RAM than secondary storage? | RAM is more expensive per gigabyte
Why is RAM not used to store personal files? | It is volatile, so the files would be lost when the power is turned off
What is ROM? | Non-volatile main memory whose contents can be read but not modified
Non-volatile main memory whose contents can be read but not modified — what term is this? | ROM (read-only memory)
What is stored in ROM? | The BIOS or firmware, including the bootstrap routine that starts the computer and initialises the hardware
Why is the startup routine stored in ROM and not RAM? | ROM is non-volatile, so the instructions are still there when the computer is switched on
What is virtual storage? | Storing data remotely on servers so that it can be accessed over a network from any connected device. It is also known as cloud storage
Storing data remotely on servers so that it can be accessed over a network from any connected device — what term is this? | Virtual storage (cloud storage)
How is virtual storage an abstraction? | The data sits on hundreds of hard drives or SSDs that are formatted to act as a single piece of storage
Name three benefits of virtual storage | Capacity is easy to increase, data can be accessed from anywhere with an internet connection, and redundancy protects against hardware failure
Name three drawbacks of virtual storage | It depends on the speed of the internet connection, sensitive data is held off-site, and the ongoing costs add up
Why can virtual storage be cost-effective? | The user pays only for the storage used instead of maintaining their own storage hardware
How does virtual storage differ from virtual memory? | Virtual storage is data held remotely in the cloud. Virtual memory is secondary storage used as an extension of RAM when RAM is full
