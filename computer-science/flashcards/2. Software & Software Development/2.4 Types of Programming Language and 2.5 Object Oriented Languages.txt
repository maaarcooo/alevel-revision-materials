What is a programming paradigm? | An approach to using a programming language to solve a problem, defining how programs are structured and developed
An approach to using a programming language to solve a problem, defining how programs are structured — what term is this? | Programming paradigm
What two broad categories are programming paradigms split into? | Imperative and declarative
Which two paradigms fall under the imperative category? | Procedural and object-oriented
Which two paradigms fall under the declarative category? | Functional and logic
How does imperative programming specify computation? | By clearly specifying the exact actions to be performed, step by step
How does declarative programming specify computation? | By stating the desired result; the language determines how best to obtain it
What type of applications is declarative programming commonly used for? | Expert systems and artificial intelligence
What is meant by a multi-paradigm language? | A language that supports more than one programming paradigm (e.g. Python supports both procedural and object-oriented programming)
What is procedural programming? | A type of imperative programming that uses a sequence of instructions carried out step by step, which may be contained within procedures
What is structured programming? | A subsection of procedural programming where control flow is managed using sequence, selection, iteration, and recursion
What is sequence in structured programming? | Code is executed line by line, from top to bottom
What is selection in structured programming? | A block of code runs only if a specific condition is met, using IF statements
What is iteration in structured programming? | A block of code is executed a certain number of times or while a condition is met, using FOR, WHILE, or REPEAT UNTIL loops
What is recursion in structured programming? | A function calls itself repeatedly until a base case (which does not call the function) is met
What is the role of variables in procedural programming? | To hold the program's state, storing data values that can change during execution
How does a constant differ from a variable? | A constant stores a value that remains unchanged throughout the program
What is a subroutine? | A named block of code that can be called to perform a specific task, promoting code reuse
How does a function differ from a procedure? | A function performs a task and returns a value; a procedure performs a task but does not return a value
What types of problems is procedural programming best suited to? | Problems that can easily be expressed as a series of step-by-step instructions
What is assembly language? | A low-level language that uses mnemonics to represent machine code instructions, specific to a particular processor architecture
A low-level language using mnemonics to represent machine code instructions — what is this called? | Assembly language
What is a mnemonic in assembly language? | An abbreviation representing a machine code instruction (e.g. ADD, SUB, LDA)
How is assembly language converted to machine code? | Using an assembler
Why is assembly language described as processor-specific? | It directly interacts with the CPU's special-purpose registers, so its instruction set differs between processor architectures
What is assembly language particularly useful for? | Embedded systems and applications requiring direct hardware interaction or highly optimised performance
What is the Little Man Computer (LMC)? | A hypothetical simplified computer model used for understanding the fundamental operations and mechanics of a computer
What does the LMC instruction ADD do? | Adds the value at the given memory address to the value in the accumulator
What does the LMC instruction SUB do? | Subtracts the value at the given memory address from the value in the accumulator
What does the LMC instruction STA do? | Stores the value in the accumulator at the given memory address
What does the LMC instruction LDA do? | Loads the value at the given memory address into the accumulator
What does the LMC instruction INP do? | Allows the user to input a value, which is placed in the accumulator
What does the LMC instruction OUT do? | Outputs the value currently held in the accumulator
What does the LMC instruction HLT do? | Stops the program, preventing the rest of the code from executing
What does the LMC instruction DAT do? | Creates a labelled memory location at which data can be stored
What does the LMC instruction BRA do? | Branches unconditionally to a given labelled address, regardless of the accumulator value
What does the LMC instruction BRZ do? | Branches to a given address if the value in the accumulator is zero (conditional branch)
What does the LMC instruction BRP do? | Branches to a given address if the value in the accumulator is zero or positive (conditional branch)
What addressing mode does the LMC use? | Direct addressing
What are the two parts of a machine code instruction? | Opcode and operand
What does the opcode specify in a machine code instruction? | The instruction to be performed
What does the operand hold in a machine code instruction? | A value related to the data on which the instruction is to be performed
Where is the addressing mode specified within a machine code instruction? | It is part of the opcode
Why are addressing modes needed? | They allow access to a much greater number of memory locations than if the operand could only hold the data value directly
What is immediate addressing? | The operand is the actual value upon which the instruction is to be performed
What is direct addressing? | The operand gives the memory address that holds the value upon which the instruction is to be performed
What is indirect addressing? | The operand gives the address of a register or memory location that contains another address, where the actual data is located
What is indexed addressing? | The address of the operand is determined by adding the operand value to the value held in an index register
Why is indexed addressing useful for accessing arrays? | It allows an offset to be added to a base address, enabling efficient access to data stored contiguously in memory
How does immediate addressing differ from direct addressing? | In immediate addressing the operand is the data itself; in direct addressing the operand is the memory address where the data is stored
What is a class in OOP? | A blueprint or template for creating objects, defining their attributes and methods
A blueprint or template for creating objects with specific attributes and methods — what OOP concept is this? | A class
What is instantiation in OOP? | The process of creating an object from a class
The process of creating an object from a class — what term is this? | Instantiation
What is an object in OOP? | A specific instance of a class with its own unique values for the class's attributes
A specific instance of a class with its own state and behaviours — what is this called? | An object
What is a constructor in OOP? | A special method automatically called when an object is instantiated, typically setting the initial values of instance variables and preparing the object for use
What is an attribute in OOP? | A variable associated with a class or object that defines part of its state (e.g. name, age, colour)
How do class variables differ from instance variables? | Class variables are the attributes defined in the class template; instance variables are the specific values those attributes hold in a particular object
What is a method in OOP? | A function or procedure defined within a class that specifies the actions or behaviours objects can perform
A function or procedure defined within a class that specifies the actions objects can perform — what is this called? | A method
How are methods called on an object? | Using dot notation: objectName.methodName()
How does an instance method differ from a static method? | An instance method operates on a specific object's data; a static method belongs to the class itself and can be called without creating an object
What is the difference between a public and a private member in OOP? | A public member can be accessed by any code including external classes; a private member can only be accessed within the class itself
What access level is assumed if no public or private modifier is specified? | Public
What is a getter in OOP? | A public method that retrieves the value of a private attribute
What is a setter in OOP? | A public method that sets or updates the value of a private attribute
Why are getters and setters used instead of directly accessing attributes? | Attributes are declared private for encapsulation, so public getter and setter methods provide controlled access without exposing internal data
What is inheritance in OOP? | A mechanism allowing a derived class to take on the attributes and methods of a base class, promoting code reuse
A mechanism allowing one class to take on the attributes and methods of another class — what OOP concept is this? | Inheritance
What type of relationship does inheritance establish between classes? | An "IS-A" relationship (e.g. a Car IS-A Vehicle)
What is a base class in inheritance? | The parent class from which derived classes inherit attributes and methods (also called a superclass)
What is a derived class in inheritance? | A class that inherits attributes and methods from a base class and can add its own additional properties (also called a subclass)
What does the super keyword do in inheritance? | Refers to the superclass, allowing a subclass to access its parent's methods, attributes, or constructor
What is encapsulation in OOP? | The practice of grouping data and methods within a class and restricting direct access to internal details using access modifiers (public and private)
Grouping data and methods within a class and restricting direct access using access modifiers — what OOP concept is this? | Encapsulation
How does encapsulation protect data in a class? | Attributes are declared private so they can only be read or modified through public methods, preventing accidental or unauthorised changes
How does encapsulation relate to abstraction? | It hides internal implementation details, allowing external code to use public methods without understanding how they work internally
What is polymorphism in OOP? | A concept allowing objects of different classes to respond to the same method name with different behaviours
Objects of different classes sharing the same method name but executing different code — what OOP concept is this? | Polymorphism
What is method overriding in OOP? | Redefining a method in a subclass so it functions differently from the version inherited from the base class
What is method overloading in OOP? | Defining multiple versions of a method with the same name but different parameters, producing different results depending on the arguments passed
How does method overriding differ from method overloading? | Overriding redefines an inherited method in a subclass to change its behaviour; overloading defines the same method name with different parameters
How does polymorphism allow objects to be treated as a common group? | Objects of different derived classes can be stored as their common base class type, with each still executing its own overridden methods when called
Why does OOP promote code reuse? | Through inheritance (subclasses reuse base class code) and polymorphism (shared method interfaces across related classes)
What is functional programming? | A declarative paradigm where programs consist of function calls, often combined within each other, and closely linked to mathematics
What is logic programming? | A declarative paradigm that defines a set of facts and rules, using queries to find answers to problems
