What does thinking ahead involve when designing a solution? | Considering the components of a problem and how they will be handled, so difficulties in use are anticipated early
What is an input in computational thinking? | Any data an algorithm needs in order to run, entered by the user or passed as a parameter to a subroutine
What is an output in computational thinking? | The result passed back once the inputs have been processed, returned to the calling subroutine or sent to an output device
Which three properties of each input and output must be defined when designing an algorithm? | Data type, size and format
Why must inputs and outputs be defined explicitly before an algorithm is written? | Otherwise the algorithm is harder to create and unexpected data can cause errors later
Besides the data itself, which two aspects of an input should a designer consider? | The order in which data is input and the method of input
In what order do designers usually identify inputs and outputs? | Outputs first, from the user's requirements, then the inputs and processing needed to produce them
Give two forms of output other than a screen display | Sound from a speaker and a printed copy from a printer
Identify three inputs to an ATM program | The transaction type, the card details from a card reader, and the PIN from a keypad
Identify three outputs of an ATM program | The balance or amount shown on screen, the cash dispensed, and a printed receipt
What is a precondition? | A requirement that must be met before a program or subroutine can execute successfully
A requirement that must be met before a program or subroutine can execute successfully — what term is this? | Precondition
What happens if a precondition is not met? | The program fails to execute, crashes or returns an invalid answer
What can a subroutine safely assume once its preconditions are specified? | That the arguments passed to it meet the stated criteria
What are arguments? | The values passed into the parameters of a subroutine when it is called
In which two places can a precondition be specified? | Tested for within the subroutine's code, or stated in the documentation that accompanies it
When a precondition is stated only in documentation, who must make sure it is met? | The developer calling the subroutine
What is the advantage of stating a precondition in documentation instead of testing it in code? | The subroutine is shorter and less complex, so less time is spent debugging and maintaining it
What is the advantage of testing a precondition inside the subroutine? | Validation happens automatically, so the calling developer does not have to write extra checks
How do preconditions make a subroutine more reusable? | Its requirements are defined explicitly, so it can be put in a library and called safely from any program that meets them
What is the precondition of a pop operation on a stack? | The stack must not be empty
What is the precondition of a factorial function? | The argument must be a non-negative integer
What precondition does binary search have that linear search does not? | The list must be sorted
State two preconditions common to algorithms that search a list | The list must not be empty, and the target must be the same data type as the list's elements
Why might a bubble sort have a precondition limiting the size of its input? | Its time complexity is $O(n^2)$, so a very large list would take too long to sort
What makes a precondition acceptable as an exam answer? | It must be a condition that can be evaluated, such as "room width is greater than 0" and not just "room dimensions"
What is caching? | Storing instructions or data in cache or memory after they have been used, so they can be retrieved faster if needed again
Storing instructions or data in cache or memory after they have been used, so they can be retrieved faster if needed again — what term is this? | Caching
What is web caching? | Storing recently visited web pages and images locally so they do not have to be downloaded again
Give two benefits of caching | Frequently used data and instructions are retrieved faster than from secondary storage, and web caching frees bandwidth because content is not downloaded again
What usually performs caching in a computer system? | The operating system, automatically
What is prefetching? | Algorithms predict which instructions are likely to be needed soon and load them into cache before they are requested
Algorithms predicting which instructions are likely to be needed soon and loading them into cache before they are requested — what term is this? | Prefetching
How does prefetching differ from ordinary caching? | Caching stores data after it has been used. Prefetching loads data before it is requested
Why is prefetching not always effective? | The algorithm only makes an informed prediction, so the instructions it loads may not be the ones needed
When does caching give no benefit? | When the cached item is not needed again, because caching relies on the same data being requested more than once
Why does cache size limit the benefit of caching? | A small cache holds little data, and a larger cache takes longer to search
State a drawback of caching that concerns its implementation | It is difficult to implement, and how effective it is depends on how well the caching algorithm manages the cache
What are reusable program components? | Components that have already been written, debugged and tested, which can be transplanted into new programs
Components that have already been written, debugged and tested, which can be transplanted into new programs — what term is this? | Reusable program components
How are commonly used subroutines made available for reuse? | They are packaged into libraries
Give three kinds of reusable program component | Subroutines, classes, and implementations of abstract data structures such as stacks and queues
Why are reusable components more reliable than newly written code? | They have already been tested and their bugs dealt with
How do reusable components make a program easier to maintain? | An error is fixed once in the component, and the fix applies everywhere the component is used
What do reusable components save during development? | Time, money and resources
How can one reusable subroutine produce a variety of outputs? | By being called with different arguments
How does producing well-tested components benefit future projects? | They can be reused again, which saves development costs
How does decomposition help developers reuse components? | Breaking the problem into smaller tasks shows where existing or externally sourced components can be used
What problem can arise when using a third-party component? | It may not be compatible with the rest of the software
Why can adapting a third-party component be worse than writing a new one? | Modifying it to fit can cost more time and money than developing the component in-house
