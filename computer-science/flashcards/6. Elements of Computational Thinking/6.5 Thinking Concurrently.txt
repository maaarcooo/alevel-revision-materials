What is concurrent processing? | More than one process is in progress at the same time, so one can start before another finishes. Each process is given a slice of processor time in turn, or the processes run on different cores
More than one process being in progress at the same time, each given a slice of processor time in turn — what term is this? | Concurrent processing
What is concurrent thinking? | The mindset of spotting patterns and parts of a problem where concurrency can be applied
The mindset of spotting patterns and parts of a problem where concurrency can be applied — what term is this? | Concurrent thinking
How does concurrent thinking differ from concurrent processing? | Concurrent thinking is done by a person analysing a problem. Concurrent processing is done by a computer processor
How does concurrent processing differ from parallel processing? | Concurrent processing switches between tasks on one processor using time slices. Parallel processing runs tasks at the same instant on multiple processors or cores
Why does concurrent processing look simultaneous to a user? | Each time slice lasts only microseconds, which is far too fast for a person to notice the switching
What would happen to a second program if processes were not given time slices? | It could not start until the first had run to completion, such as a game waiting for a virus scan to finish
What are dependencies? | Tasks that rely on other tasks in order to start or complete
Tasks that rely on other tasks in order to start or complete — what term is this? | Dependencies
Give an example of a dependency | A roof cannot be put on a house until the walls are built, and the walls cannot be built until the foundation is in place
How do you decide which parts of a problem can be tackled at the same time? | Assess which parts are related and identify the dependencies. Parts that do not rely on each other can be tackled concurrently
In the task of recording the number plate and colour of each passing car, what is the concurrent thinking approach? | Record both the plate and the colour of one car before moving to the next, instead of all the plates and then all the colours
When can the data sets of a batch program be processed in parallel on multiple cores? | When they do not relate to, rely on or interact with each other
How can several different batch programs make progress on one processor? | They are interchanged and pipelined using concurrent processing
State the benefit of concurrent processing for throughput | More tasks are completed in a given time
State the benefit of concurrent processing for a user while a long task runs | The user can still interact with the computer, because long-running tasks do not hold up short ones
How does concurrent processing reduce the time wasted waiting for user input? | The processor swaps to another task, then swaps back when an operating system interrupt signals the input
State the drawback of concurrent processing when many users or tasks are involved | Each process gets only a time slice, so processes take longer to complete
What overhead does concurrent processing introduce? | Coordinating and switching between processes, which reduces throughput
What must be implemented when concurrent processes read and write the same data? | Record locking, so two processes cannot change the data at once, which makes the programming more complex
Why are some tasks unsuited to concurrent processing? | Not every task can be broken up into parts that are performed in turn
What can operating system scheduling algorithms do to concurrent processes? | Prioritise some processes over others, so those processes can finish sooner
State an advantage of parallel processing for repetitive calculations on large amounts of data | The work is split over several processors, which speeds it up, as in image or video editing
How do GPUs use parallel processing? | They split the computations of a 3D scene between many cores
State a drawback of parallel processing that concerns communication | Processors working simultaneously may need to communicate, which adds overhead and delay
Why might a task not benefit from parallel processing? | Some tasks run faster, or are optimised to run, on a single processor
Give an example of concurrent processing in a flight simulator | The user's plane, the other planes and the weather do not always interact, so each can be processed in its own time slices
Which three things should an exam answer about an example of concurrent processing include? | The example, how it acts concurrently, and why it needs to be concurrent
