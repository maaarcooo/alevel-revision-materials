What is recursion? | When a subroutine calls itself during its execution, until a stopping condition is met
A subroutine calls itself during its execution — what technique is this? | Recursion
What three features must a recursive subroutine have? | A stopping condition (base case), a call to itself for any other input, and a stopping condition that is reached after a finite number of calls
What is the base case of a recursive subroutine? | The condition under which it returns a result without calling itself again
What happens if a recursive subroutine never reaches its base case? | It keeps calling itself until the call stack runs out of memory, causing a stack overflow that crashes the program
What is the call stack? | A last-in-first-out data structure that records the subroutines currently being executed, so each one returns to the right place when it ends
What is a stack frame? | The block of data pushed onto the call stack for one subroutine call: its parameters, local variables and return address
What is added to the call stack each time a recursive call is made? | A new stack frame
What is unwinding in recursion? | Once the base case is reached, stack frames are popped one at a time, with each call returning its result to the call before it
What causes a stack overflow in a recursive program? | So many nested calls are made that the call stack runs out of memory

Why does recursion use more memory than iteration? | Every call adds a stack frame to the call stack, whereas a loop reuses the same variables
Why is a recursive subroutine harder to trace than a loop? | The program state is spread across many nested calls, each with its own copies of the variables
Give one advantage of iteration over recursion | There is no call stack overhead, so it uses less memory and cannot cause a stack overflow

What is the scope of a variable? | The section of code in which the variable can be accessed

Why are global variables discouraged? | They can be overwritten unintentionally from anywhere in the program, which makes it harder to test and maintain
When is a global variable appropriate? | For a value needed throughout the whole program, e.g. a constant or a configuration setting

State one drawback of using local variables | Data needed by another subroutine has to be passed as a parameter or handled as a return value, which makes the program more complex to write

What is modular programming? | Splitting a large program into smaller, self-contained modules, each of which carries out one task

What is a parameter? | A variable in a subroutine's definition that receives a value passed in when the subroutine is called
What is an argument? | The actual value passed to a subroutine when it is called
What happens when a parameter is passed by value? | A copy of the value is given to the subroutine, so changes made inside it do not affect the original
A copy of the value is given to the subroutine and discarded when the subroutine ends — which parameter passing method is this? | Passing by value
What happens when a parameter is passed by reference? | The address of the value is given to the subroutine, so changes made inside it change the original
The address of the value is given to the subroutine, so the original can be changed — which parameter passing method is this? | Passing by reference
How is the parameter passing method shown in OCR pseudocode? | byVal or byRef after the parameter name, e.g. function multiply(x:byVal, y:byRef)
In an OCR exam, how are parameters passed unless stated otherwise? | By value

Why is passing by value safer than passing by reference? | The subroutine cannot change the original data, so there are no unintended side effects
Why is passing by reference more efficient for a large data structure? | No copy is made, which saves memory and the time taken to copy it
Why must an array be passed by reference to a procedure that updates it? | A procedure cannot return the updated array, so the changes must be made to the original for them to be kept when it ends
Why can passing by reference cause unexpected side effects? | The subroutine changes the original data, which other parts of the program may rely on
