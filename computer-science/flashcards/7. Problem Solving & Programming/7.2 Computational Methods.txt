What are computational methods? | Problem-solving techniques that use algorithms and mathematical models to solve problems with a computer
What is a computable problem? | A problem that can be solved using an algorithm within a finite, realistic amount of time
A problem that can be solved using an algorithm within a finite, realistic amount of time — what is this called? | A computable problem
What do problems that can be solved computationally typically consist of? | Inputs, outputs and calculations
Which three resources limit the problems that can be solved computationally in practice? | Processing power, processor speed and memory
Why might a computable problem be impractical to solve? | The resources or the length of time it needs are too great
How have advances in technology affected which problems can be solved computationally? | More problems have become feasible to solve as processing power, speed and memory have grown
What kind of problem is unsuitable for a computational solution? | One that depends on human judgement or creativity, e.g. low staff morale or a poor marketing strategy
What is problem recognition? | Identifying that there is a problem to be solved and clearly defining what the problem is
Identifying that there is a problem to be solved and clearly defining what it is — what is this called? | Problem recognition
Who states what is required of the finished product during problem recognition? | The stakeholders
What two things are analysed to define the system requirements? | The strengths and weaknesses of the current solution, and the data involved (inputs, outputs, stored data and volume of data)
What is problem decomposition? | Continually breaking a problem down into smaller sub-problems until each can be solved by a self-contained subroutine
Continually breaking a problem down into smaller sub-problems until each can be solved by a self-contained subroutine — what is this called? | Problem decomposition
What is the aim of problem decomposition? | To reduce the complexity of a problem by splitting it into smaller sections that are easier to understand and solve
How does decomposition allow a project to be delivered faster? | Sub-problems can be developed in parallel by different teams and then combined
How does decomposition differ from abstraction? | Decomposition splits a problem into smaller parts, while abstraction removes unnecessary detail from it
What is divide and conquer? | A technique that repeatedly splits a problem into smaller sub-problems of the same kind, solves them, and combines the results
A problem is repeatedly split into smaller sub-problems of the same kind, which are solved and their results combined — what technique is this? | Divide and conquer
What are the three stages of divide and conquer? | Divide, conquer and merge (combine)
What happens in the divide stage of divide and conquer? | The problem is split into smaller sub-problems, typically halving its size each time
What happens in the conquer stage of divide and conquer? | Each sub-problem is solved, often recursively
What happens in the merge stage of divide and conquer? | The solutions to the sub-problems are recombined to form the solution to the whole problem
Name three algorithms that use divide and conquer | Binary search, merge sort and quick sort
How does binary search apply divide and conquer? | It compares the middle item with the target and discards the half that cannot contain it, then repeats on the half that remains
How many times can a problem of size $n$ be halved before one item is left? | About $\log_2 n$ times, which is why binary search has time complexity $O(\log n)$
Why does divide and conquer cope well with large problems? | Halving the problem at each step means the time taken grows slowly as the problem grows
Give one drawback of divide and conquer | It usually relies on recursion, which risks a stack overflow and is difficult to trace
How can divide and conquer take advantage of a multi-core processor? | Independent sub-problems can be solved at the same time on different cores
Why is abstraction used when solving a problem computationally? | It removes unnecessary detail, so the programmer can focus on the core aspects of the solution
How can abstraction allow existing code to be used in a solution? | The problem may be reduced to one that has already been solved, so pre-written modules and libraries can be used
How do levels of abstraction make a large project more manageable? | The project is split into simpler components that different teams can work on, with the details of other layers hidden
What is abstract thinking used for once a problem has been abstracted? | Representing real-world entities with computational elements, such as tables and variables
What is backtracking? | A technique that builds a solution step by step by exploring a path, and returns to the previous decision point to try another path when one fails
A solution is built step by step, returning to the previous decision point to try another path whenever one fails — what technique is this? | Backtracking
How is backtracking usually implemented? | Recursively
Which graph traversal is an example of backtracking? | Depth-first traversal
How is backtracking used in a depth-first traversal of a tree? | When a leaf node is reached, the traversal goes back to the most recent node that still has unvisited children
How would backtracking solve a maze? | Follow a path until a dead end is reached, then go back to the most recent junction and try a different route
Give one benefit of backtracking | It is guaranteed to find a solution if one exists
Why can backtracking be slow? | It may have to search the entire solution space, so its time complexity can be high
Why might backtracking not give the best solution? | It stops at the first solution it finds, which is not necessarily the optimal one
What is data mining? | Analysing large sets of data to identify patterns, trends and correlations that are not immediately obvious
Large sets of data are analysed to identify patterns, trends and correlations that are not immediately obvious — what technique is this? | Data mining
How do businesses use the results of data mining? | To predict future trends from past data, which informs decisions such as stock levels and marketing
Give an example of data mining in retail | Analysing purchase histories to find which products sell at certain times of year, so enough stock is ordered in advance
Why must data mining comply with data protection law? | It often involves processing personal data, which is regulated by the GDPR
Give one benefit of data mining | It finds patterns and trends that people would not spot, so better predictions and decisions can be made
Give two practical drawbacks of data mining | It needs powerful computers with a lot of processing power, and inaccurate data gives inaccurate results
What can data mining not tell you about a pattern it finds? | The reason why the pattern exists
What are heuristics? | A rule-of-thumb approach that finds an approximate, good enough solution quickly, instead of the optimal one
A rule-of-thumb approach that quickly finds a good enough solution instead of the optimal one — what is this? | Heuristics
When are heuristics used? | When finding the optimal solution would take an unreasonable amount of time or resources
What is the trade-off when using heuristics? | Speed against accuracy: a solution is found faster, but it is not guaranteed to be the best
What is an intractable problem? | A problem whose solution takes an unreasonably long time to find
A problem whose solution takes an unreasonably long time to find — what is this called? | An intractable problem
Name two problems where heuristics are used | The Travelling Salesman Problem and pathfinding with the A* algorithm
How do heuristics differ from backtracking? | Heuristics make educated guesses to reach an approximate solution quickly, while backtracking explores paths systematically until it finds a solution
What is performance modelling? | Using mathematical models and simulation to predict how a system will perform before it is used in the real world
Mathematical models and simulation are used to predict how a system will perform before it is used in the real world — what technique is this? | Performance modelling
Why is performance modelling used for safety-critical systems? | A real trial run would be unsafe, e.g. for the systems on an aeroplane
Give one advantage of performance modelling over real performance testing | It is cheaper and less time-consuming
How does performance modelling show whether a system will cope with heavy use? | It simulates the system under different loads, such as large volumes of data or large numbers of users
What do the results of performance modelling help a company to judge? | The capabilities of the system, how it will cope in different environments, and whether it is safe to implement
Give one limitation of performance modelling | The results are only as accurate as the data and assumptions put into the model
What is pipelining as a computational method? | Splitting a task into smaller tasks that are carried out concurrently, with the output of one process becoming the input of the next
A task is split into smaller tasks that run concurrently, with the output of one becoming the input of the next — what computational method is this? | Pipelining
What three steps are involved in applying pipelining to a task? | Break the task into smaller tasks, put them in order so each output feeds the next input, and run as many as possible at the same time
How can pipelining shorten the manufacture of a car? | Tasks that do not depend on each other, such as developing the engine and the chassis, are done at the same time
What does the pipe symbol (vertical bar) do in Unix? | Passes the output of one command to the input of the next command
What is visualisation? | Presenting data or a problem in a visual form that is easier for people to understand
Data or a problem is presented in a visual form that is easier for people to understand — what technique is this? | Visualisation
Name three ways in which data can be visualised | Graphs, charts and tables
Give one benefit of visualisation | Trends and patterns that were not obvious in the raw data become easier to identify
Give one limitation of visualisation | It shows what the data looks like but cannot explain why, and different people may interpret it differently
Name three diagrams used to visualise the design of a system | Flowcharts, UML diagrams and wireframes
